## 3. 人工验证清单（需用户执行，浏览器体验）

> 以下各项无法通过命令行验证，需用户在浏览器/局域网设备上手动验证。

### 3.1 播放三层动态流（2026-08 修订后尚未验证）

> 各常见格式的处理路径速查见 [media.md](media.md) §4.3（含容器 × 编码组合表与目标机差异）。
1. 直连播放（mp4/h264 秒开、拖动流畅、续播、播完从头）。
2. **MKV+H.264+AAC**：Chrome/Edge 直连播放（Chromium 支持 Matroska）；Firefox/Safari 或 `canPlayType` 返回
   空时 → **Remux 层**：点播放后出现短暂「转换中」，随后从转换出的 MP4 播放，进度条全片可拖、可拖动 seek、
   非 Live。`data_dir/remux/` 出现 `<id>.mp4`，再次播放秒开（命中缓存）。**前提是先重扫源填充 `audio_codec`**；
   未重扫（audio_codec 为空）的 MKV 一律判「不可播放」（保守，避免无声）。
2a. **MKV 音频不可拷贝**：重扫源后，AC3/EAC3/DTS/PCM 音轨的 MKV 走 **Transcode HLS**（分片转码，音频转 AAC，
    `data_dir/hls/<session>/` 出现分片，几秒起播）；AAC/MP3 音轨的 MKV 正常 Remux/Direct（Remux 纯拷贝秒级完成）。
3. **MKV+HEVC**：装了「HEVC 视频扩展」/硬件支持的机器直连可播；未装的机器 → **Transcode HLS**：点播放后按需
   转码（第一个分片有等待），进度条显示全片时长可拖、无 Live 标识，拖动即转对应分片。`data_dir/hls/<session>/`
   出现分片，会话空闲约 10 分钟被清理。
4. **MKV+AC3/EAC3**：浏览器（Chromium/Firefox）通常无 Dolby 解码器 → `canPlayType` 返回空 → 走 **Transcode HLS**，
   音轨转 AAC 后有声（几秒起播，`data_dir/hls/<session>/` 出现分片）；个别带 Dolby 解码的设备可直连（原 AC3 音轨）。
5. **AVI/WMV（h264 视频）**：AVI/WMV 容器不可直连 → 音频可拷贝（AAC/MP3/无声）走 **Remux**（纯拷贝）；
   音频不可拷贝（AC3/EAC3/DTS/PCM）或视频编码不兼容（如 MPEG4/VC1）→ **Transcode HLS**；若 transcode 不可用
   （未配置 ffmpeg）→ 播放按钮禁用，详情/播放栏「格式工厂转换」一键送达格式工厂。
6. **fMP4（segmented）**：不可直连，但 h264 时 `remux_playable=true` → 走 Remux（流拷贝成常规 MP4 后 Range
   播放）；无法 Remux 时引导格式工厂。
7. **faststart 标记**：详情页对 mp4 家族显示「可直连播放」「非快速启动」；非 faststart MP4 能播但拖动需缓冲。
7a. **详情页技术卡片**：详情栏「技术信息」卡片展示播放方式徽标（直接/重封装/转码/无法在线）+ 技术信息
    （容器+MIME/视频/音频摘要/时长大小/分段/快速启动）+ **逐流播放处理**（容器/视频/音频在所选层下如何
    处理，全部为自然语言键值对 + 语义色 + **有损/无损徽标**——不再有旧式「不支持前端解码」死路警告，
    也不展示原始探测串/后端能力标志等难懂行）+ 音轨清单（各轨 codec/声道/语言/处理方式/有损无损徽标，
    默认轨标注）+ 字幕清单（外部字幕直接显示、内封字幕自动提取显示、位图字幕标注「仅可烧录」）。
    卡片正文统一字号、颜色区分层级；窄屏（手机竖屏）时键值对纵向堆叠（键靠左值靠右）不省略。
7a1. **单集详情永远带 series 上下文**：某单集属于系列时，从首页/搜索卡片或深链 `/library/video/:id`
     打开详情会自动跳转补齐为 `/series/:id/video/:videoId`（顶部出现「返回系列」条），单集详情不再有
     「所属系列」跳转链接。
7b. **字幕多轨菜单**：播放器字幕菜单列出全部字幕源（侧边 + 内封文本轨），可切换；详情页技术卡片同步展示同一清单。
7b1. **多音轨选轨（2026-09）**：双音轨 MKV（如古惑仔 国语/粤语，AC3 走 HLS；或 h264+AAC 双轨走 Remux）播放时，
     播放器「设置」菜单出现「音轨」项（与倍速/画质/字幕同一 UI），列出各轨（title/语言/声道）；点选粤语 →
     短暂重载后**保持进度**切到粤语音轨，再次切回国语同理；换轨后 HLS 生成新会话分片、Remux 命中各自缓存
     （`data_dir/remux/<id>-a1.mp4`）。单音轨文件不显示该菜单；Direct 层（浏览器原生可解的多音轨）暂只播默认轨。
7b2. **播放选择记忆（2026-09）**：
     a. 双音轨 MKV 选「粤语」、切字幕到某轨、调音量后退出 → 重新进入该视频播放，**自动应用**粤语音轨 + 所选
        字幕 + 音量（无需手动再选；HLS 层换轨会重建新会话）。
     b. **仅手动刷新**：进入播放自动应用记忆时**不产生写入**（只读）；再次手动切换音轨/字幕/音量 → 记忆更新，
        下次播放应用新值；把字幕「关闭」后再进播放仍保持关闭（空串记忆）。
     c. 播放中途手动切字幕再换音轨（重载）→ 字幕保持刚手选的那轨（不会回退到更早的记忆）。
     d. 缓存管理页「播放选择记忆」区块按视频列出（含音轨/字幕/音量摘要，剧集按系列分组），单条「删除」或
        「清空全部」后，再次播放该视频回到默认轨/默认字幕/默认音量。
     e. 单集详情页进度小节「清除」（图标，ToolTip 提示）不影响选择记忆（两者互不干扰）；删除视频后其选择记忆
        随之消失。
     f. 静音后退出再进入 → 仍为静音态。
     g. **系列共享（2026-09 修订）**：某系列第一集选「国语」音轨 + 「简体中文」字幕 + 调音量 → 播放该系列
        第二集/后续集，**自动应用同名**音轨/字幕 + 音量；某集无该名称轨道时该字段回默认。任一集手动改选
        → 整部系列记忆更新（同名跟着变）。
     h. **系列记录优先**：某单集曾独立播放过（有自身记忆），加入系列后系列无记录 → 播放用单集自身记忆；
        在系列任一集手动改选后 → 系列记录产生，此后各集（含该集）都按系列记录，单集自身记录被忽略。
     i. **详情页展示与清除**：系列详情页「播放历史」卡内「配置缓存」小节显示（音轨/字幕名称 + 音量，注
        「整部系列共享」），清除图标（ToolTip）后各集回退到单集自身记忆/默认；单集详情页同一小节显示有效记忆
        （来自系列时注「来自系列」），清除图标删除当前生效的记录（系列记录或单集记录），再次播放回默认。
7c. **三端能力差异**：同一 MKV h264+aac 在 Chrome（直连）与 Firefox/Safari（Remux）播放均正常；同一 HEVC 在
    带扩展的机器（直连）与不带扩展的机器（Transcode HLS）播放均正常。

### 3.1.1 单集 / 系列管理模型（2026-08 定稿，需用户手动验证，浏览器体验）
1. **标记为系列**：文件页签对媒体源内某文件夹点「标记为系列」→ 任务面板出现任务，完成后该文件夹在视频库
   成为系列（名=文件夹名，成员=文件夹直接一级视频，文件名序）。重复标记不产生重复系列。
2. **媒体源外路径**：对媒体源外的路径点「标记为系列」→ 拒绝并提示「请先将该目录添加为多媒体源」。
3. **嵌套拒绝**：在已建系列文件夹内的子文件夹点「标记为系列」→ 拒绝（系列不能嵌套）。
4. **扫描维护成员**：往系列文件夹里放入新视频文件后重扫该源 → 新文件自动成为系列成员；把成员文件移出
   系列文件夹后重扫 → 该成员脱离系列变为游离单集；移走最后一个成员后系列被清理。
5. **单集详情同步**：改名/移动某单集文件（仍在该媒体源内）→ 打开单集详情显示「源文件已改名或移动」警告，
   点「同步」后路径更新、警告消失；删除该文件 → 详情显示「源文件不存在」，点「移除这个单集」后记录消失。
6. **系列详情同步**：删掉系列某个成员文件或往系列文件夹放入新文件 → 打开系列详情显示「与磁盘不一致」警告
   及差异清单，点「同步」后成员列表收敛（消失成员移除、新文件纳入、序号重排）。
7. 磁盘外部直接删文件后：单集详情提示 missing、系列详情提示 missing，均不会自动删库（需手动同步/移除）。
8. 手动编辑的标题/描述/标签在扫描/同步后**不被覆盖**；**成员标题同样受 `title_source` 保护（2026-09 修订）**：
   手动改过（批量改名/单集详情编辑）的成员标题不再被同步还原为文件名，仅未手动编辑过的成员标题随同步刷新；
   系列显示名（`shows.name`）同样不被扫描/标记/同步覆盖。
8a. **系列显示名（2026-09，ADR-015 修订）**：标记为系列后，系列详情页元数据卡铅笔编辑显示名（默认=文件夹
   名）；改名后再触发扫描/重新标记/同步，显示名**保持不变**；文件页签「标记为系列」不再因文件夹名变化而
   覆盖已编辑的显示名。
8b. **系列观看进度（2026-09）**：把系列若干集看到中途 → 系列详情页「播放历史」卡内「观看进度」小节显示
    「已观看 X / N 集 · 整体进度 Y%」+ 进度条；点该小节清除图标（ToolTip「清空本系列进度」）→ 进度条归零、
    各成员行续播进度消失；播放某集退出后返回系列详情，进度小节与成员行即时刷新。
8c. **系列成员拖拽重排（2026-09，ADR-015 修订）**：系列详情成员列表头部一行 = 左侧标题「剧集列表 N 集」+
     右侧**可展开按钮组容器**（同一 `rounded-md border p-1` 容器）：平时只显示六个点的拖拽把手按钮（hover 提示
    「编辑模式」），点击后进入编辑模式并在容器内展开「按当前显示名称排序 / 恢复文件名序 / 批量修改显示名称 /
     退出编辑模式」四个图标按钮。关闭（默认）时行不可拖拽、文字可选中复制；开启后列表 `select-none` 防文本选择，按住
     某行拖动——**原行留在原位变半透明，列表内 absolute 定位同宽 ghost（无编号）垂直居中跟随鼠标**（不用 fixed，
     避免 transform 坐标系偏移；不遮挡其它行 hover）；**落到某行中间带 → 与目标行交换**（整行蓝圈高亮），
    **落到两行之间的上下边缘 → 插入**（蓝色插入线），松手后顺序持久化（刷新/重新进入保持）；编号槽与按钮/
     链接不是拖拽把手。重排后再重扫/同步：**顺序不被还原为文件名序**，新放入的文件追加到末尾。
8d. **排序 / 恢复文件名（2026-09，ADR-015 修订）**：编辑模式下两个排序按钮——
     **按当前显示名称排序**（前端按 `episode_title || title` 字典序排序后走 `POST /api/series/{id}/order`，
     手动改过的标题生效）、**恢复文件名序**（`POST /api/series/{id}/resort`：清 `sort_manual` 并按文件名序
     重绑成员 1..N，纯 DB 操作，不依赖根目录可达；此后重扫/同步恢复「按文件名自动维护、新文件按文件名插入」
     的默认行为。**手动编辑过的成员标题（`title_source='manual'`）在此过程中保留**）。
8e. **批量修改显示名称（2026-09）**：编辑模式下点铅笔图标 → 弹出模态框（查找/替换 + 无视大小写 + 正则开关 +
    原/新两列预览），点「开始替换」后各成员显示名经 `PATCH /api/videos/{id}` 更新为新的 `title`（`title_source`
    → `manual`）；之后**扫描/同步不再把显示名还原为文件名**（成员标题受 `title_source` 保护，2026-09 修订）。

7.4 左栏分隔条：盘符/常用/多媒体源之间横条可上下拖动调整各栏占比，刷新后保持。
7.5 Windows 特殊目录/文件（$RECYCLE.BIN、System Volume Information、desktop.ini、Thumbs.db 等）在
    列表中不显示（按 HIDDEN/SYSTEM 属性过滤，非名称匹配）；普通用户手动设隐藏属性的文件同样被隐藏。
7.6 常见文件类型显示不同图标 + 柔和颜色（视频蓝/音频紫/图片绿/压缩包琥珀/文档灰/代码青绿），整体不花哨。
7.7 「多媒体视图」按钮：点击后列表仅剩文件夹与视频/音乐文件，按钮蓝色激活态；再点恢复全部。
7.8 底部工具抽屉（剪贴板容器，2026-08）：
    a. 勾选若干文件点「复制」：右侧列底部滑出抽屉，与列表同宽、把列表底边顶起、不遮列表也不占左侧栏，
       列表收窄出现滚动条；工具栏右侧状态文本不再出现「剪贴板 N 项」。
    b. 抽屉头部显示「待复制/待移动 · N 项」+ 每行小图标与文件名（悬停显示完整路径）；点行尾 ✕ 移除单项，
       移除最后一项后抽屉自动收起；「全部清除」清空抽屉并收起。
    c. 抽屉与勾选解耦：入抽屉后再勾选/取消勾选不影响抽屉内容；再次选择一批点「剪切/复制」则替换抽屉内容。
    d. 剪切后在其他目录「粘贴」成功：任务完成后抽屉清空收起（原文件已移动）；复制粘贴成功后抽屉保留，
       可再切到其它目录继续粘贴。
    e. 抽屉内容跨目录保持（剪切/复制后导航到别的目录再粘贴）。
7.9 抽屉尺寸（2026-08 增量）：剪贴板抽屉整体更高（行距放宽）；只选了 1~3 个文件时抽屉仍保持约 5 行高的
    舒适尺寸（`min-h`），多个文件时内部滚动。
7.10 全选/反选（2026-08 增量）：点「全选」勾选当前目录全部条目、点「反选」反转勾选（均对当前可见
     条目生效）；空目录时两按钮禁用。
7.11 批量重命名（2026-08 增量）：
     a. 勾选 ≥2 项后工具栏「批量重命名」按钮可点（1 项或 0 项禁用）。
     b. 点击打开抽屉：VS Code 式替换栏（查找/替换两个输入框 + 无视大小写/正则两个开关 + 开始替换按钮）；
        下方左右两栏「原文件 ↔ 新文件名」逐行对应预览，变化行绿色高亮，行数多时可滚动。
     c. 打开时无匹配（查找无命中）→「开始替换」禁用；正则非法 → 输入框红框 + 提示 + 禁用。
     d. 点「开始替换」：磁盘文件实际改名、抽屉关闭、勾选清空、列表刷新；存在失败项时错误逐条列出。
     e. 直接点抽屉右上「撤销」关闭抽屉 = 放弃，不做任何重命名。
7.12 手动标记系列（2026-08 增量 + 2026-09 显示名修订；「标记为单集」与离散资源概念已清除）：
     a. 勾选仅文件夹点「标记为系列」：文件夹整体打包成一个系列（**系列显示名默认=文件夹名**，成员按文件名
        序 1..N）；勾选含文件时该按钮禁用。**未选文件夹且当前目录含视频时按钮也可用**，此时把**当前所在
        文件夹**标记为系列。含二级文件夹的文件夹只对其中不含子文件夹的叶子文件夹打包；外层直接视频不入库。
     b. 标记某文件夹为系列后，视频库中该系列显示名 = 文件夹名（首次），系列内单集名（title/episode_title）
        刷新为文件名（去扩展名），搜索可命中新名。显示名已手动编辑过则**不被覆盖**（ADR-015 修订）。
     c. 媒体源内**已扫描入库**的文件夹：改名文件夹 + 改所有文件名后再「标记为系列」→ 因 `root_path` 已变化，
        **系列按路径重建**为「新系列」（未编辑过显示名时显示名=新文件夹名、单集名=新文件名），旧系列清空被
        清理，不残留空白系列；**未入库的新文件夹**（如新文件）标记后归置为新系列（属于媒体源）。
     d. 把其它系列的文件移入某文件夹后「标记为系列」→ 目标系列吸收该成员，原系列失去该成员（变空则消失）。
     e. 删除某系列文件夹下的一个视频文件后「标记为系列」→ 该系列**刷新子集**，被删单集从库中消失
        （文件页签永久删除文件/文件夹 → 库中对应视频记录**立即**移除，见 §3.11.6）。
     f. 重复标记同一文件夹（系列）不产生重复系列（复用已有 show）。
8. **多媒体源（2026-08 核心重构）**：
   8.1 在某目录点「标记为多媒体源」：按钮变紫激活态（显示「多媒体源」），左侧「多媒体源」区立即出现
       该路径，header 任务面板出现「扫描多媒体源 · <目录名>」并推进；扫描完成后视频库出现其下视频。
   8.2 标记后视频库按单集/系列归组（系列仅来自手动「标记为系列」，扫描只维护既有系列成员，见 §3.1.1）；
       扫描过程中库可实时看到陆续入库，但任何时刻不会出现某个系列的「半套」元数据。
   8.3 源行「重新扫描」按钮：新增/删除文件后手动重扫，库随之增删；未变化的文件保留手动编辑的标题/评分。
   8.4 取消标记（再点按钮，经强确认）：该源下所有已入库单集与系列**从库中消失**（含其系列、标签、历史与
       封面/缩略图），磁盘文件不受影响；源从左侧区移除；其它源的内容不受影响。
   8.4a 取消标记含系列成员时：该源所属系列随之清空并消失（空系列清理）；把另一目录再标记为源并扫描后
       库可重新建立。
    8.5 嵌套拒绝（2026-08 修订）：把 `C:\Videos\Movies`（位于源 `C:\Videos` 内）标记为源 → 拒绝并提示
        「多媒体源不允许嵌套」；把 `C:\Videos` 的父目录标记为源同样拒绝。历史遗留嵌套源仍可正常扫描（路由
        表防御），但不再能新建。
   8.6 跨源移动：把视频文件从源 A 移动到源 B，重扫 B 后库中仍是同一条记录（历史/手动元数据保留），
       A 重扫不会把它删成两条。
   8.7 离线状态：源目录（如移动硬盘根）被拔出/改名后，左侧源行显示「离线」徽标；手动重扫报错但**库
       内容不动**；插回后重扫恢复正常。

### 3.9 工具页签 · 格式工厂（2026-09，需用户手动验证，浏览器体验）
1. 顶部出现「工具」页签：左侧垂直工具栏列出工具（现为格式工厂），右侧为对应面板；`?tool=id` 在 URL 中，
   刷新/深链恢复到该工具。
2. 文件页签选中一个 `.mkv` 文件 → 工具栏「格式工厂」→ 切到工具页签并自动选中格式工厂，待转换清单显示
   「Movie → …\Movie.mp4」。
3. 选中一个含多集视频的文件夹 → 格式工厂 → 清单显示「系列/文件夹 → …\Show (MP4)\」。
4. 点「开始转换」：header 任务面板与格式工厂面板都出现「转换 · 名称」任务；**进度条推进并显示剩余时间**
   （约 X 分钟），不再是无尽转圈；文件夹批量转换子任务「转换 <名>（n/N）」。
5. 转换完成后：原目录出现 `Movie.mp4`（或 `Show (MP4)\ep1.mp4…`），**源文件原封不动**；重复转换同名已存在时
   输出自动变 `Movie (1).mp4`。
6. 用 mp4 播放：视频库重新扫描后该 mp4 可**直连播放**（秒开、进度条可拖动、无「Live」直播标识）；
   MKV 播放器卡在「Live 直播模式」的问题通过先转成 mp4 根治。
7. 勾选非视频文件一起转换：任务面板显示该文件被跳过并给出原因（不是视频文件），其余正常转换。
8. **位图字幕自动降级**：转换一个内封 PGS/VobSub 位图字幕的 MKV（无损拷贝必然失败）→ 自动烧录重编码：
   产物为 h264 mp4，**字幕显示在画面里**（始终可见、不可关闭），音频若为 DTS/Vorbis/AC3 等会自动转为 AAC，
   浏览器播放有画面有声音有字幕。
9. 转换一个音频为 **AC3/DTS** 的 MKV（无位图字幕，走无损路径）→ 产物 mp4 音频被转成 **AAC 192k**，视频仍
   无损拷贝；用 Windows 自带播放器/其它桌面播放器打开有声音（不再报「不支持的 AC3 编码」），浏览器同样出声。
10. **精确进度**：转换大 MKV 时，进度条与「预计还需 X」基于 ffmpeg 的 `out_time/真实时长` 精确推进
    （时长缺失的流拷贝再按「已写入字节/源大小」1:1 兜底），不会停在低百分比不动、也不靠拍脑袋系数。
11. **操作面板预设**：格式工厂顶部操作面板三个预设（快速 MP4 / H.264 MP4 / H.265 MP4）点击即填充参数，
    激活态高亮；改动任一参数后状态变为「已自定义参数」。
12. **H.264/H.265 预设**：对同一 MKV 分别选 H.264、H.265 转换，产物视频分别为 h264 与 HEVC 且可播放；
    勾选「烧录首选字幕进画面」后字幕显示在画面里、无残留字幕轨；不勾选时文本字幕保留为 mov_text 轨。
13. **转换队列**：任务进行中再提交新批次可继续入队（任务面板与队列两处都显示进度）；历史任务区分成功/失败，
    每行标注所用预设；转换完成后再选新文件，队列历史仍保留。
14. **未选择文件时操作面板遮罩**：直接进工具页签（无待转换文件）→ 操作面板被半透明遮罩覆盖、不可操作，并提示
    在文件页签选择；在文件页签选择后遮罩消失。
15. **预设仅作快速填充**：参数表单字段持续存在（无损流拷贝时 CRF 置灰但仍在）；点快速 MP4/H.264/H.265 只把
    对应参数填进表单，切换预设不改变表单字段布局。
16. **探测信息与禁用**：选择一个含 PGS 位图字幕的 MKV → 操作面板提示「含位图字幕，快速 MP4 将自动降级为烧录」，
    待转换行显示「位图字幕」徽标；选择 AC3 音频的 MKV → 提示将自动转 AAC 且「保留原音」选项置灰不可选；选择
    无字幕轨的视频 → 烧录字幕复选框禁用并提示「所选文件均无字幕轨」。
17. **rmvb 等额外类型**：文件页签选中一个 `.rmvb` 文件（普通视图可见）→「格式工厂」按钮可点、加入待转换后
    探测并转换成功（RealVideo 流无法无损封装，自动降级为 h264 重编码，产物可播放）；目录里混有 rmvb 时
    「开始转换」一并处理。多媒体视图仍不显示 rmvb（只认媒体库视频集）。
18. 极端情况下仍失败（如 ffmpeg 无 libass 且源又无法拷贝）：任务失败显示 ffmpeg 错误，源文件不受影响。

### 3.10 工具页签 · 缓存管理（2026-08，需用户手动验证，浏览器体验）

1. **孤儿打包清理**：工具页签 →「缓存管理」，孤儿区块显示总数/总大小 + 各类明细（封面·缩略图·字幕）；
   手动删除库中某视频记录后再在磁盘上留一份同名缓存文件 → 孤儿数增加；点「清理孤儿」→ 确认后孤儿清零。
2. **字幕缓存按视频列出**：播放过内封字幕 MKV 后，字幕区块按视频列出提取出的 vtt（同一剧集的集数合并
   显示在剧集标题下）；每行显示「轨 N · 文件名 · 大小」。
3. **单条删除字幕**：字幕行点「删除」→ 确认后该 vtt 消失；再次播放该视频，字幕重新提取、列表恢复。
4. **按视频清空字幕**：视频行「清空该视频」→ 该视频全部字幕缓存消失；「清空全部」→ 全部字幕缓存清空。
5. **封面/缩略图无删除入口**：封面/缩略图区块只显示说明与孤儿提示，正在使用的封面图无法删除（符合预期）。

### 3.11 统一资源进口/出口管线（2026-08，需用户手动验证，浏览器体验）

1. **复制入库**：文件页签把某个 .mkv 复制到媒体源内目录（剪贴板粘贴）→ 任务完成后，该视频**立即**出现在
   视频库（无需扫描），详情页技术卡片有完整 probe 数据。
2. **移动入库/保身份**：把媒体源内视频移动到同源另一目录 → 视频库**立即**更新路径，续播/标签/手动标题
   保留；详情页不再提示「源文件已改名或移动」。
3. **移出即出库**：把媒体源内视频移动到**媒体源外**（非任何源）→ 视频库**立即**移除该视频（无需等扫描）。
4. **改名同步**：把媒体源内视频重命名 → 库中标题（文件派生）与路径立即更新；手动编辑过的标题不被覆盖。
5. **格式工厂产物即时入库**：转换一个 MKV → 完成后产物 MP4 **立即**出现在视频库（封面稍后由异步缩略图
   任务补齐），源文件不变。
6. **删除即时出库**：文件页签永久删除媒体源内视频 → 库中记录**立即**消失；若它是系列成员，系列成员列表
   随之收敛。
7. **媒体源禁止嵌套**：对源内目录再「标记为多媒体源」→ 拒绝并提示不允许嵌套。
8. **手动标题保护**：编辑某视频标题 → 重扫源/刷新元数据后标题**不被还原**为文件名；**系列成员标题同样受
   `title_source` 保护（2026-09 修订）**：手动改过的成员标题（批量改名/单集详情编辑）不随同步还原，仅未手动
   编辑过的成员标题随文件名刷新。
