## 3. 风险与对策

| 风险 | 对策 |
|---|---|
| 大目录首次扫描耗时长 | 增量指纹 + 进度可见 + 可中断重扫 |
| NTFS 符号链接/junction 歧义 | 只跟踪普通文件+目录，链接默认跳过 |
| 源文件被外部改名/移动 | file_id 全局匹配校正路径 |
| 多媒体源根不可达被误判「全部删除」 | 扫描前置可达性探测：不可达即中止、不动库 |
| 嵌套/重叠多媒体源 | 新建源禁止嵌套；路由表防御历史遗留嵌套 |
| 剧集命名不规范归组错误 | 系列只由用户显式创建，识别错误手动兜底 |
| 浏览器编码兼容 | 三层动态流运行期判定（见 media.md §4） |
| SQLite 并发写冲突 | WAL + 单写者串行 |
| 多终端并发操作互踩 | 会话相互独立；写操作收敛串行 |
| 口令弱导致泄露 | 默认随机口令、登录失败限速 |

## 5. 人工验证清单

> 按功能域归并的核对要点；各域行为规格见领域文档。

### 5.1 播放（media.md §4）

1. 播放页签：库详情/系列成员点播放 → 切到播放页签，视频占左侧，剧集列表占右侧窄栏；点击页签栏「视频库」返回浏览
2. 播放页签空态：首访无播放时显示引导；浏览器后退/前进在库与播放页签间正确切换
3. mp4/h264 直连秒开、可拖、续播正常；播完存完整时长
4. MKV h264+aac：Chromium 直连；Firefox/Safari 走 Remux
5. MKV AC3/EAC3/DTS/PCM → Transcode HLS 几秒起播有声
6. AVI/WMV h264+aac → Remux；编码不兼容 → Transcode
7. 多音轨切换保持进度；播放选择记忆自动应用
8. 多终端并发：两设备同播互不挤占
9. 切出播放页签自动暂停；切回不丢失进度

### 5.2 单集 / 系列管理（backend.md §4）

1. 标记系列：名=文件夹名、成员=一级子文件文件名序
2. 扫描维护成员：新文件自动追加；移出成员脱离为游离单集
3. 同步：单集 moved→同步按钮；missing→移除按钮
4. 保护语义：手动标题/系列显示名扫描永不覆盖
5. 排序：拖拽重排持久化；恢复文件名序

### 5.3 文件页签

1. 盘符/pin/多媒体源三段侧栏、面包屑跳转
2. 复制/移动后台任务带进度
3. 批量重命名预览/关闭即撤销

### 5.4 统一管线即时性（backend.md §8）

复制到媒体源 → 视频立即入库；移动 → 路径即时更新；改名 → 标题即时更新；删除 → 记录即时消失

### 5.5 格式工厂（media.md §3.1）

1. MKV 转 MP4 后可直连秒开
2. 位图字幕自动烧录降级；AC3/DTS 自动转 AAC
3. 进度条精确推进并显示剩余时间

### 5.6 缓存管理

概览数字准确；默认只显示有缓存的系列；Remux 仅在归属处清理；预生成 Job 进度可见

### 5.7 实时通道

登录建连、登出断开；扫描期间收到 events.* 推送、任务面板无轮询
