## 1. 已实现能力（现状）

- **认证**：单口令 + 会话 Cookie，多终端独立会话（ADR-002）。
- **文件页签**：绝对路径浏览、剪贴板复制/移动（jobs）、重命名/批量重命名/删除、pin、
  多媒体源标记/取消/重扫、标记系列。
- **扫描与索引**：指纹 `(file_id,size,mtime)` 增量、file_id 全局匹配（跨源移动保身份）、
  嵌套防御、离线保护（根不可达不动库）；jobs 队列 + worker；库写长任务互斥串行。
- **统一进出口管线（ADR-017）**：文件操作与格式工厂产物在操作完成瞬间即入库/出库；
  move/rename 先 Ingest 后 Evict 保住身份、续播与手动元数据；标题经 title_source 保护不被覆盖。
- **播放（ADR-006）**：三层动态流（Direct/Remux/Transcode，运行期 canPlayType 判定）+ 封面 +
  字幕（侧边优先+内封文本轨提取）+ 多音轨选轨 + Vidstack + 移动端伪全屏。
- **播放选择记忆**：单集级 + 系列级（按轨道名称匹配，系列记录优先），可重建缓存可清除。
- **格式工厂**：Faststart MP4 副本（无损流拷贝优先、位图字幕自动烧录降级）、三预设、精确进度与 ETA。
- **历史续播**：10s 节流保存、距片尾 20s 内不续播、播完存完整时长；详情页合并卡「播放历史」
  （观看进度 + 配置缓存两小节），系列聚合「已看 X/N 集」。
- **媒体库（ADR-015/018）**：单集必须归属媒体源；系列为用户显式创建容器（绑定根目录），
  手动排序/恢复文件名序/批量改名/显示名编辑且扫描永不覆盖；关联 = 显式分组互相可见；
  首页行（继续观看/最近添加）。
- **搜索 / 元数据**：FTS5；元数据仅手动编辑（刮削已移除；简介/年份/类型字段已删除）。
- **前端**：页签 keep-alive、栏位栈视频库、响应式 UI、工具页签（格式工厂/缓存管理/开发者工具）。
- **实时通道（ADR-021）**：WS 推送 + RPC、事件桥全量转发域事件、jobs 进度推送零轮询。

## 3. 人工验证清单（需用户在浏览器/局域网设备执行）

> 按功能域归并的核对要点；各域行为规格见领域文档对应章节。

### 3.1 播放三层动态流（media.md §4）

1. mp4/h264 直连秒开、可拖、续播正常；自然播完存完整时长——详情/成员行显示 100%、
   「继续观看」不再包含、再播从片头。
2. MKV h264+aac：Chromium 直连；Firefox/Safari 走 Remux（`remux/<id>.mp4` 出现、二播秒开、全片可拖）。
   前提先重扫填充 audio_codec；未重扫的 MKV 保守判不可播。
3. MKV AC3/EAC3/DTS/PCM → Transcode HLS 几秒起播有声（分片目录 `hls/<session>/` 出现，
   空闲 ~10 分钟清理）；HEVC 装扩展/硬件直连否则 Transcode。
4. AVI/WMV h264+aac → Remux；编码不兼容 → Transcode；ffmpeg 未配置 → 按钮禁用引导格式工厂。
5. fMP4(segmented) 不可直连走 Remux；非 faststart MP4 能播但提示拖动需缓冲。
6. 详情技术卡片：播放方式徽标、逐流处理说明、有损/无损徽标、音轨/字幕清单正确。
7. 多音轨：双轨 MKV 设置菜单出现「音轨」，切换保持进度；HLS 生成新会话分片、Remux 各轨独立缓存。
8. 播放选择记忆：进播放自动应用上次音轨/字幕/音量；仅手动切换才写入；静音记忆生效；
   系列共享按名称匹配（某集无该名称轨道回默认）；系列记录优先于旧单集记录；
   详情页「配置缓存」小节展示并可清除（区分来自系列/自身）。
9. 多终端并发：两设备同播互不挤占，HLS 会话各自独立。

### 3.2 单集 / 系列管理（backend.md §4）

1. 标记系列：名=文件夹名、成员=一级子文件文件名序；重复标记不重复建；媒体源外路径拒绝；
   系列内子文件夹嵌套拒绝。
2. 扫描维护成员：新文件自动追加；移出成员脱离为游离单集；最后一个成员移走后系列清理。
3. 同步：单集 moved→同步按钮收敛路径；missing→移除按钮；系列 out_of_sync→差异清单+一键同步；
   磁盘外部删文件只提示不自动删库。
4. 保护语义：手动标题/成员标题/系列显示名在扫描、重新标记、同步后均不被还原覆盖。
5. 排序：拖拽重排持久化（重扫不还原、新文件追加末尾）；恢复文件名序清 sort_manual；
   按当前显示名排序生效；批量改名后显示名即时更新且不再被扫描还原。
6. 取消标记多媒体源：整源单集与系列从库消失、磁盘不动；其它源不受影响。
7. 离线：拔盘源行显离线徽标、重扫报错但库不动；插回重扫恢复。

### 3.4 统一管线即时性（backend.md §8）

1. 复制到媒体源 → 视频立即入库（含 probe 数据）；移动 → 路径即时更新、历史保留；
   改名 → 文件派生标题即时更新、手动标题不动；移出所有源 → 立即出库；
   删除 → 记录即时消失；格式工厂产物完成即入库。

### 3.5 格式工厂（media.md §3.1）

1. 基本：MKV 转 MP4 后可直连秒开；源文件原封不动；同名输出 (N) 递增。
2. 位图字幕 MKV → 自动烧录降级（画面内有字幕、不可关闭）；AC3/DTS 音频 → 自动转 AAC 有声。
3. 进度条精确推进并显示剩余时间；文件夹批量子任务 n/N；预设快速填充、参数禁用规则正确；
   rmvb 自动降级转换成功。
