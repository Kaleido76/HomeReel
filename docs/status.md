## 1. 已实现能力（现状）

- **认证与会话**（ADR-002）：单口令 + 会话 Cookie；多终端独立会话，登出只清自身。
- **泛用文件浏览器（「文件」页签，2026-08 重构）**：绝对路径浏览所有本地盘符（fixed/removable，排除
  网络盘）、pin 常用路径、剪贴板式剪切/拷贝/粘贴/重命名/删除（copy/move 走 jobs 后台任务带进度，
  删除永久 + 强确认）；**全选/反选**当前目录条目；**批量重命名**（勾选 ≥2 项 → 工具栏入口 →
  VS Code 式替换栏抽屉，字面/正则/无视大小写，原↔新名逐行预览，`POST /api/files/renames` 批量同步）；
  **多媒体源标记**（`media_sources`）：任意目录标记为源即入队全量扫描，视频自动入库；**取消标记（经强
  确认）→ 该源下所有已入库单集与系列从库中消失**（磁盘文件不受影响，`DeleteBySource` + `VideoDeleted` 清理
  缓存）；源列表展示离线/扫描中状态、行内可手动重扫；**手动标记系列（2026-08 管理面定稿）**：工具栏「标记为
  系列」把所选文件夹（或当前目录）打包为系列（须位于媒体源内，否则拒绝；防嵌套；成员 = 根目录直接一级
  子文件）。**离散单集/离散系列概念已彻底清除**。文件页签永久删除 → 立即同步清理库中对应记录。
  文件内容不入库，目录跳转后端实时读取。详见 [backend.md](backend.md) §10 / [frontend.md](frontend.md) §1.1。
- **扫描与索引**：多媒体源全量扫描，指纹 `(file_id,size,mtime)` 增量、**file_id 全局匹配**（跨源移动
  保持身份）、路由表跳过嵌套子源子树、源根不可达时中止且不动库、HIDDEN/SYSTEM 条目不索引；`jobs`
  队列 + Worker（probe/thumbnail/scan_source/convert，崩溃恢复）；**原子化**：单视频元数据单条提交、
  「把成员绑定到系列」单事务提交。库写长任务（scan/mark/probe/sync）互斥串行。
- **长时任务系统（jobs 独立组件）**：用户可见长时任务（扫描/转换）带展示名与进度；扫描按文件数上报
  确定进度、格式工厂文件夹转换按文件数上报进度、未知时长任务显示不确定条；前端 header「后台任务」
  按钮 + 弹出面板（JetBrains 风格，`RefreshCw` 有任务时转圈）。
- **播放（2026-08 修订：纯 Range 直连，无 HLS）**：可播放性由前端运行期 `canPlayType()` 核对
  （`lib/playability.ts`：probe 容器/编码 → MIME/codecs，MKV/HEVC 由目标机能力天然决定）；
  不可直连 → 播放按钮禁用 + 详情/播放栏「格式工厂转换」引导（一键把该文件送进格式工厂）。
  后端 `direct_playable` 为保守 fallback。封面；字幕（侧边 `.srt/.vtt/.ass` 优先，内封文本轨按需提取为
  vtt）；Vidstack 播放器。
  删除视频时同时清理封面/缩略图。
- **格式工厂（2026-09，替代原「重封」页签）**：文件页签选中视频/文件夹 → 工具栏「格式工厂」→ 工具页签内
   **操作面板**选预设（快速 MP4 无损流拷贝 / H.264 / H.265 重编码，参数可微调、改动标记「已自定义」）→
   「开始转换」，经 `POST /api/convert`（携带 `params`）入队：单集→同目录 `X.mp4`、系列/文件夹→同级
   `X (MP4)\`，绝不覆盖源文件；转换后浏览器直连播放、可拖动。**输入类型按
   `files.IsConvertible`**（媒体库视频集 + rmvb/rm/vob/asf/mts/dat/divx/f4v/swf/ogm 等 ffmpeg 可读容器），
   rmvb 等自动降级重编码。队列区分「进行中（进度条 + ETA）」与「历史（成功/失败，标注所用预设）」，
   可随时追加批次。详见 [media.md](media.md) §3.1。
- **历史续播**：`history` 表（user=`local`）；前端 10s 节流保存、进入 seek（距片尾 20s 内不续播、播完归零）。
- **媒体库（单集/系列，2026-08 管理面定稿）**：单集是唯一基本实体（必须归属媒体源）；**系列是用户显式
  创建的管理容器**，绑定根目录（`seasons.root_path`），成员 = 根目录直接一级子文件、文件名序 1..N，系列名 =
  文件夹名（无季号）。**扫描只维护既有系列成员关系、绝不建系列**；手动添加系列 / 详情页同步（单集
  `CheckVideo/SyncVideo`、系列 `CheckSeries/SyncSeries`）按需收敛。`series_links` 弱关联手动增删；首页行
  （继续观看/最近添加）。离散资源（`manual_resources`/`resource_id`）已整体移除（2026-08 管理面换代，库
  清空重建）。
- **搜索**：FTS5（`videos_fts` external content + 触发器，bm25 排序），`search_text` 由 store 层维护。
- **元数据（手动）**：ffprobe 自动填充技术字段（时长/编码/分辨率）；标题/简介/评分/标签等由手动 PATCH
  编辑；封面 `POST /api/videos/{id}/cover` 落盘。**刮削子系统（TMDB 在线 + NFO 侧边文件）已整体移除
  （2026-08）**。
- **前端**：多 Router 页签 keep-alive、栏位栈视频库、Vidstack 播放器、响应式 UI、工具页签（格式工厂）——详见
  [frontend.md](frontend.md)。

## 3. 人工验证清单（需用户执行，浏览器体验）

> 以下各项无法通过命令行验证，需用户在浏览器/局域网设备上手动验证。

### 3.1 基础播放与库（2026-08 修订后尚未验证）
1. 直连播放（mp4/h264 秒开、拖动流畅、续播、播完从头）。
2. **MKV+H.264+AAC**（Chrome/Edge）直连播放、非 Live、可拖动——**前提是先重扫源填充 `audio_codec`**；
   未重扫（audio_codec 为空）的 MKV 一律判「不可播放」（保守，避免无声）。
2a. **MKV 无声保护**：重扫源后，DTS/PCM 音轨的 MKV 播放按钮禁用并提示转换；AAC/AC3/Opus 音轨的正常直连。
3. **MKV+HEVC**：装了「HEVC 视频扩展」/硬件支持的机器直连可播；未装的机器播放按钮禁用并提示转换。
4. **MKV+AC3** 在 Chrome/Edge 有声；若个别机器无声 → 从 `playability.ts` 的 audioTokens 移除 ac3/eac3。
5. **AVI/WMV/DTS 音频**：播放按钮禁用，详情/播放栏「格式工厂转换」一键送达格式工厂。
6. **fMP4（segmented）**：判不可直连，引导转换。
7. **faststart 标记**：详情页对 mp4 家族显示「可直连播放」「非快速启动」；非 faststart MP4 能播但拖动需缓冲。
8. 手机/平板局域网访问播放。
9. 同名 `.srt/.vtt` 字幕出现在字幕菜单。
10. 标记多媒体源后全量扫描：视频以单集入库、不产生任何系列；重复扫描不重复入库；`audio_codec`/`faststart` 被填充。
11. 单集/系列两视图、系列详情成员按文件名序展示。
12. 系列间关联手动增删、可跳转。
13. 首页「继续观看」随历史变化。
14. 标签增删后可被搜索命中。
15. 上传封面后播放页/海报墙更新。

### 3.1.1 单集 / 系列管理模型（2026-08 定稿，需用户手动验证，浏览器体验）
1. **标记为系列**：文件页签对媒体源内某文件夹点「标记为系列」→ 任务面板出现任务，完成后该文件夹在视频库
   成为系列（名=文件夹名，成员=文件夹直接一级视频，文件名序）。重复标记不产生重复系列。
2. **媒体源外路径**：对媒体源外的路径点「标记为系列」→ 拒绝并提示「请先将该目录添加为多媒体源」。
3. **嵌套拒绝**：在已建系列文件夹内的子文件夹点「标记为系列」→ 拒绝（系列不能嵌套）。
4. **扫描维护成员**：往系列文件夹里放入新视频文件后重扫该源 → 新文件自动成为系列成员；把成员文件移出
   系列文件夹后重扫 → 该成员脱离系列变为游离单集；移走最后一个成员后系列被清理。
5. **单集详情同步**：改名/移动某单集文件（仍在该媒体源内）→ 打开单集详情显示「源文件已改名或移动」警告，
   点「同步」后路径更新、警告消失；删除该文件 → 详情显示「源文件不存在」，点「移除这个单集」后记录消失。
6. **系列详情同步**：删掉系列某个成员文件或往系列文件夹放入新文件 → 打开系列详情显示「与磁盘不一致」警告
   及差异清单，点「同步」后成员列表收敛（消失成员移除、新文件纳入、序号重排）。
7. 磁盘外部直接删文件后：单集详情提示 missing、系列详情提示 missing，均不会自动删库（需手动同步/移除）。
8. 手动编辑的标题/描述/标签在扫描/同步后**不被覆盖**；成员标题（文件名）会随同步刷新为磁盘文件名。

7.8 底部工具抽屉（剪贴板容器，2026-08）：
    a. 勾选若干文件点「复制」：右侧列底部滑出抽屉，与列表同宽、把列表底边顶起、不遮列表也不占左侧栏，

    b. 抽屉头部显示「待复制/待移动 · N 项」+ 每行小图标与文件名（悬停显示完整路径）；点行尾 ✕ 移除单项，

    c. 抽屉与勾选解耦：入抽屉后再勾选/取消勾选不影响抽屉内容；再次选择一批点「剪切/复制」则替换抽屉内容。
    d. 剪切后在其他目录「粘贴」成功：任务完成后抽屉清空收起（原文件已移动）；复制粘贴成功后抽屉保留，
       可再切到其它目录继续粘贴。
    e. 抽屉内容跨目录保持（剪切/复制后导航到别的目录再粘贴）。
7.9 抽屉尺寸（2026-08 增量）：剪贴板抽屉整体更高（行距放宽）；只选了 1~3 个文件时抽屉仍保持约 5 行高的
    舒适尺寸（`min-h`），多个文件时内部滚动。
7.10 全选/反选（2026-08 增量）：点「全选」勾选当前目录全部条目、点「反选」反转勾选（均对当前可见
     条目生效）；空目录时两按钮禁用。
7.11 批量重命名（2026-08 增量）：
     a. 勾选 ≥2 项后工具栏「批量重命名」按钮可点（1 项或 0 项禁用）。
     b. 点击打开抽屉：VS Code 式替换栏（查找/替换两个输入框 + 无视大小写/正则两个开关 + 开始替换按钮）；
        下方左右两栏「原文件 ↔ 新文件名」逐行对应预览，变化行绿色高亮，行数多时可滚动。
     c. 打开时无匹配（查找无命中）→「开始替换」禁用；正则非法 → 输入框红框 + 提示 + 禁用。
     d. 点「开始替换」：磁盘文件实际改名、抽屉关闭、勾选清空、列表刷新；存在失败项时错误逐条列出。
     e. 直接点抽屉右上「撤销」关闭抽屉 = 放弃，不做任何重命名。
7.12 手动资源（离散/系列，2026-08 增量）：
     a. 勾选若干文件/文件夹点「标记为单集」：header 任务面板出现「标记单集 · …」并推进；完成后视频库
        出现这些单集。手动资源**不**在文件页签左侧出现。
     b. 勾选仅文件夹点「标记为系列」：文件夹整体打包成一个系列（文件夹名为系列名，成员按文件名序 1..N）；
        勾选含文件时该按钮禁用。**未选文件夹且当前目录含视频时按钮也可用**，此时把**当前所在文件夹**
        标记为系列。含二级文件夹的文件夹只对其中不含子文件夹的叶子文件夹打包；外层直接视频不入库。
     c. 媒体源内的路径标记：不出现资源标记（仅库内局部刷新归组），视频归属媒体源。
     d. 标记某文件夹为系列后，视频库中该系列名刷新为文件夹名，系列内单集名（title/episode_title）也刷新
        为文件名（去扩展名），搜索可命中新名。
     d1. 媒体源内**已扫描入库**的文件夹：改名文件夹 + 改所有文件名后再「标记为系列」→ 该系列**原地刷新**
        （系列名=新文件夹名、单集名=新文件名），不新建、不残留空白系列；**未入库的新文件夹**（如新文件）
        标记后归置为新系列（属于媒体源，不当作离散资源）。
     d2. 把其它系列的文件移入某文件夹后「标记为系列」→ 目标系列吸收该成员，原系列失去该成员（变空则消失）。
     d3. 删除某系列文件夹下的一个视频文件（磁盘或文件页签）后「标记为系列」→ 该系列**刷新子集**，被删单集
        从库中消失；文件页签永久删除文件/文件夹 → 库中对应视频记录**立即**移除（无需标记/扫描）。
     e. 视频详情页打开离散资源视频：若源文件已不存在，显示「源文件已不存在（可能已被移动或删除）」提示；
        点击「释放（解除绑定）」经强确认后仅删除该视频已入库元数据，磁盘文件不受影响，详情页退出回到库；
        删除离散资源的最后一个成员后，库中不再残留对应资源。
     f. 重复标记同一文件夹（系列）不产生重复系列（复用已有 show）。
8. **多媒体源（2026-08 核心重构）**：
   8.1 在某目录点「标记为多媒体源」：按钮变紫激活态（显示「多媒体源」），左侧「多媒体源」区立即出现
       该路径，header 任务面板出现「扫描多媒体源 · <目录名>」并推进；扫描完成后视频库出现其下视频。
   8.2 标记后视频库按单集/系列自动归组（**严格目录判定**，见 8.8）；扫描过程中库可实时看到陆续入库，
       但任何时刻不会出现某个系列的「半套」元数据。
   8.3 源行「重新扫描」按钮：新增/删除文件后手动重扫，库随之增删；未变化的文件保留手动编辑的标题/评分。
   8.4 取消标记（再点按钮，经强确认）：该源下所有已入库单集与系列**从库中消失**（含其系列、标签、历史与
       封面/缩略图），磁盘文件不受影响；源从左侧区移除；其它源的内容不受影响。
   8.4a 取消标记含系列成员时：该源所属系列随之清空并消失（空系列清理）；把另一目录再标记为源并扫描后
       库可重新建立。
   8.5 嵌套源路由表：把 `C:\Videos` 和 `C:\Videos\Movies` 都标记为源，各自扫描互不重复；子源区域只
       由子源扫描。
   8.6 跨源移动：把视频文件从源 A 移动到源 B，重扫 B 后库中仍是同一条记录（历史/手动元数据保留），
       A 重扫不会把它删成两条。
   8.7 离线状态：源目录（如移动硬盘根）被拔出/改名后，左侧源行显示「离线」徽标；手动重扫报错但**库
       内容不动**；插回后重扫恢复正常。
8.8 **严格自动归组 + 系列 ↔ 物理目录严格对应（2026-08）**：
   a. 同一目录 ≥2 个 `Show.S01E01`/`第01集` 风格文件 → 自动成一个系列（同季多集）；**目录内不能有
      任何不匹配的视频对象**——混入一个 `Foo 特别篇.mkv` 之类不匹配文件时**整目录不自动归组**；
      `2+2` 两个系列混放、`Bar 1/Bar 2` 旁放一个无关文件也**整目录不归组**（全部保持单集）。
   b. `Show/Season 1/` 下 ≥2 个文件自动成系列（季号取目录、剧名取上级目录）；`Show/第01集.mkv` 这类
      剧名在父目录的也成系列；目录里只有 1 个文件**不成系列**。
   c. 无编号但同前缀系列（`XX冒险记：北京/上海/广州`）自动成系列；`720p/x264/10bit` 等发行后缀、
      文件名里的年份（如 `Foo 2011`）不影响归组判定。
   d. **统一产出（2026-08 增量）**：判定为系列后**不提取系列名**——系列名 = 文件夹名（`Season N`
      取上级目录名、季号仅内部结构字段），成员排序号统一为**文件名序 1..N**（不再提取 SxxEyy/Part 编号）。
      手动标记系列与自动归组共用同一身份规则，**扫描与手动入库幂等**：同一文件夹共用同一 show，不互相
      搬成员、不产生空白系列；扫描结束清理无成员的空系列。**系列显示名只有名字**（无「第 N 季」后缀）。
   e. 系列详情只列出实际成员（按文件名序连续编号）。
   f. **无电影/tv 类型**：`Bar 1/Bar 2`（Part/数字后缀）也按普通系列归组（同季文件名序），界面统一
      显示「系列剧集」；电影/tv 区分后续走标签。
   g. 非多媒体文件（字幕 .srt/.ass、nfo、封面等）可在系列目录里任意混放，不影响归组。

### 3.9 工具页签 · 格式工厂（2026-09，需用户手动验证，浏览器体验）
1. 顶部出现「工具」页签：左侧垂直工具栏列出工具（现为格式工厂），右侧为对应面板；`?tool=id` 在 URL 中，
   刷新/深链恢复到该工具。
2. 文件页签选中一个 `.mkv` 文件 → 工具栏「格式工厂」→ 切到工具页签并自动选中格式工厂，待转换清单显示
   「Movie → …\Movie.mp4」。
3. 选中一个含多集视频的文件夹 → 格式工厂 → 清单显示「系列/文件夹 → …\Show (MP4)\」。
4. 点「开始转换」：header 任务面板与格式工厂面板都出现「转换 · 名称」任务；**进度条推进并显示剩余时间**
   （约 X 分钟），不再是无尽转圈；文件夹批量转换子任务「转换 <名>（n/N）」。
5. 转换完成后：原目录出现 `Movie.mp4`（或 `Show (MP4)\ep1.mp4…`），**源文件原封不动**；重复转换同名已存在时
   输出自动变 `Movie (1).mp4`。
6. 用 mp4 播放：视频库重新扫描后该 mp4 可**直连播放**（秒开、进度条可拖动、无「Live」直播标识）；
   MKV 播放器卡在「Live 直播模式」的问题通过先转成 mp4 根治。
7. 勾选非视频文件一起转换：任务面板显示该文件被跳过并给出原因（不是视频文件），其余正常转换。
8. **位图字幕自动降级**：转换一个内封 PGS/VobSub 位图字幕的 MKV（无损拷贝必然失败）→ 自动烧录重编码：
   产物为 h264 mp4，**字幕显示在画面里**（始终可见、不可关闭），音频若为 DTS/Vorbis/AC3 等会自动转为 AAC，
   浏览器播放有画面有声音有字幕。
9. 转换一个音频为 **AC3/DTS** 的 MKV（无位图字幕，走无损路径）→ 产物 mp4 音频被转成 **AAC 192k**，视频仍
   无损拷贝；用 Windows 自带播放器/其它桌面播放器打开有声音（不再报「不支持的 AC3 编码」），浏览器同样出声。
10. **精确进度**：转换大 MKV 时，进度条与「预计还需 X」基于 ffmpeg 的 `out_time/真实时长` 精确推进
    （时长缺失的流拷贝再按「已写入字节/源大小」1:1 兜底），不会停在低百分比不动、也不靠拍脑袋系数。
11. **操作面板预设**：格式工厂顶部操作面板三个预设（快速 MP4 / H.264 MP4 / H.265 MP4）点击即填充参数，
    激活态高亮；改动任一参数后状态变为「已自定义参数」。
12. **H.264/H.265 预设**：对同一 MKV 分别选 H.264、H.265 转换，产物视频分别为 h264 与 HEVC 且可播放；
    勾选「烧录首选字幕进画面」后字幕显示在画面里、无残留字幕轨；不勾选时文本字幕保留为 mov_text 轨。
13. **转换队列**：任务进行中再提交新批次可继续入队（任务面板与队列两处都显示进度）；历史任务区分成功/失败，
    每行标注所用预设；转换完成后再选新文件，队列历史仍保留。
14. **未选择文件时操作面板遮罩**：直接进工具页签（无待转换文件）→ 操作面板被半透明遮罩覆盖、不可操作，并提示
    在文件页签选择；在文件页签选择后遮罩消失。
15. **预设仅作快速填充**：参数表单字段持续存在（无损流拷贝时 CRF 置灰但仍在）；点快速 MP4/H.264/H.265 只把
    对应参数填进表单，切换预设不改变表单字段布局。
16. **探测信息与禁用**：选择一个含 PGS 位图字幕的 MKV → 操作面板提示「含位图字幕，快速 MP4 将自动降级为烧录」，
    待转换行显示「位图字幕」徽标；选择 AC3 音频的 MKV → 提示将自动转 AAC 且「保留原音」选项置灰不可选；选择
    无字幕轨的视频 → 烧录字幕复选框禁用并提示「所选文件均无字幕轨」。
17. **rmvb 等额外类型**：文件页签选中一个 `.rmvb` 文件（普通视图可见）→「格式工厂」按钮可点、加入待转换后
    探测并转换成功（RealVideo 流无法无损封装，自动降级为 h264 重编码，产物可播放）；目录里混有 rmvb 时
    「开始转换」一并处理。多媒体视图仍不显示 rmvb（只认媒体库视频集）。
18. 极端情况下仍失败（如 ffmpeg 无 libass 且源又无法拷贝）：任务失败显示 ffmpeg 错误，源文件不受影响。
